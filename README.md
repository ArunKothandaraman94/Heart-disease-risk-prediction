# Heart Disease Risk Prediction

An end-to-end healthcare analytics project using R, machine learning, and Power BI to predict heart disease risk and present meaningful insights through interactive dashboards.

## Project Objectives

- Clean and prepare heart disease data using R
- Perform exploratory data analysis
- Identify important heart disease risk factors
- Build and compare machine learning models
- Evaluate model performance
- Export predictions for Power BI
- Create an interactive healthcare dashboard

## Tools and Technologies

- R
- Machine Learning
- Power BI
- Git
- GitHub
